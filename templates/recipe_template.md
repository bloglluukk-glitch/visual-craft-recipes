# 레시피 제목

상태: experimental / tested-on-model / observed-in-production 중 실제 근거에 맞게 선택.

## 해결할 문제

독자가 겪는 구체적인 증상과 원하는 결과.

## 입력과 보존 기준

입력 자산·출처·역할, 지킬 것과 바꿀 것.

## 실행

도구·모델·버전·설정, baseline, 수정 조건, 복사 가능한 프롬프트.

## 비교 설계

고정 조건·바꾼 변수, 반복 수와 시드 지원 여부.

## 검수와 수정

통과·실패·판정 불가 기준과 다음 수정.

## 결과

실행 전이면 명시. 실행 후에는 성공·실패를 포함한 전체 결과와 관측·해석을 구분.

## 출처와 한계

배경 사실의 출처, 작성자의 판단, 아직 검증하지 않은 범위.
