# AI 생성 참고 이미지

이번 v0.2의 PNG 5개는 내장 `image_gen.imagegen`으로 새로 생성한 이미지다. 가상의 무브랜드 제품과 설명용 그림이며 고객 원본·외부 사진을 복제하지 않았다. SVG 원본은 제공하지 않는다.

| 파일 | 역할 | 주의할 범위 |
|---|---|---|
| bottle_reference.png | 유리병 형태·캡·무문자 라벨·재질의 이미지 참고 | 실제 제품 사진이나 광학 측정 자료가 아님 |
| metal_reference.png | 은색 새틴 원통 제품 형태·재질의 이미지 참고 | 실제 금속 사진·표면 측정이 아님 |
| glass_lighting.png | 밝은/어두운 배경의 윤곽을 보여주는 설명 그림 | 같은 설정을 적용한 baseline/recipe 실험 결과가 아님 |
| metal_lighting.png | 반사 띠·어두운 경계·일정한 표면색 설명 | 실제 렌더 설정을 재현·측정한 결과가 아님 |
| motion_plan.png | 제품 부분 회전과 카메라 접근의 계획 설명 | 실제 영상 프레임·모션 검증 결과가 아님 |

생성 프롬프트, 이미지별 참고 관계·크기·파일 해시는 [GENERATION_RECORD.json](GENERATION_RECORD.json)에 기록했다. 사용한 도구는 내장 imagegen이며 모델 이름·시드·생성 설정은 도구가 노출하지 않아 추정하지 않았다. 저장된 프롬프트만으로 동일 픽셀 결과를 재현할 수 있다고 보장하지 않는다.

제품 PNG를 모델의 이미지 참고 입력으로 붙인다. 제품 사진으로 보이지만 모두 AI가 만든 가상 제품이다. 참고 권한은 형태·라벨 배치·재질에 두고, 레시피에서 변경할 배경·조명·움직임을 따로 명시한다. 실제 제품은 사용 가능한 사진으로 교체하고 출처·권한을 기록한다.

설명 그림은 독자가 원하는 화면을 이해하는 용도로 사용한다. 가운데 제품의 미세한 비율이나 반사는 입력과 다를 수 있으며 픽셀 동일성 검사를 통과한 편집본으로 취급하지 않는다. 영상 설명의 원형 화살표는 제품의 부분 회전 방향을 뜻하며 360도 회전 지시가 아니다.

v0.1의 기하 도식과 SVG는 이번 공개판에 포함하지 않는다.
