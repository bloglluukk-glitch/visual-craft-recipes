# Visual Craft Recipes

**디자이너의 시각 판단을, 복사해서 실험할 수 있는 제작 지시로.**

조명·반사·움직임을 구체적인 화면 조건으로 나누고, 결과가 어긋났을 때 무엇부터 고칠지 기록하는 한국어 레시피 모음입니다. 프롬프트는 영어로 제공하며, 설명과 검수 기준은 한국어입니다.

**v0.2.1 — experimental / 레시피 비교 실험 전.** 현재 묶음에는 레시피, 프롬프트, AI로 생성한 가상 제품 참고 이미지와 설명 그림 5개, 실험 기록 양식이 있습니다. 이미지 생성은 수행했으며 baseline과 recipe의 동일 조건 비교·모델별 성능 검증·실제 영상 생성은 아직 수행하지 않았습니다.

## 첫 실험 방법

1. 레시피를 읽고 `examples/`의 해당 brief를 확인합니다.
2. `assets/`의 제품 PNG를 형태·재질 참고 입력으로 사용합니다. 모든 제품은 AI가 만든 가상 제품이며, 제품 뒷면이나 실제 치수·물성을 확인한 자료는 아닙니다. 자기 제품을 쓰려면 사용 가능한 사진으로 바꾸고 기록합니다.
3. 이미지 입력을 지원하는 도구에 해당 PNG와 `prompts/`의 텍스트를 넣습니다. 도구 이름·모델·날짜·크기·참고 강도·시드 지원 여부를 기록합니다. 이 저장소는 특정 도구의 이미지 태그나 API 형식을 강제하지 않습니다.
4. 동일한 입력·모델·출력 크기에서 baseline과 recipe를 비교합니다. 지원하면 같은 시드를 사용합니다. 시드가 없으면 각 조건을 최소 3회 실행하고 결과 전부를 남깁니다. 3회는 소규모 탐색 제안이며 통계적 성능 보장이 아닙니다.
5. `templates/experiment_record.json`의 관측을 채웁니다. 레시피의 검수표로 통과·실패·판정 불가를 구분합니다.

영상 레시피는 제공된 금속 제품 PNG 또는 검수한 다른 시작 이미지를 선택합니다. 두 영상 조건에 같은 시작 이미지를 사용하고, 새 이미지가 필요하면 그 과정도 기록합니다. 다른 시작 이미지를 넣은 결과는 같은 조건으로 비교하지 않습니다. 생성 참고 이미지도 실제 제품 사진과 구분해 기록합니다.

## 무엇을 공유하나요?

- **판단:** 예쁜 결과보다 먼저 지켜야 할 형태·정보·움직임을 정하는 방법.
- **입력:** 특정 고객·브랜드에 기대지 않는 AI 생성 가상 제품 이미지.
- **실행:** baseline과 의도별 프롬프트, 도구와 조건을 기록하는 brief.
- **검수:** 실패를 발견하는 체크리스트와 수정·합성·3D로 넘길 기준.
- **기여:** 성공 결과뿐 아니라 실패 결과도 함께 제안할 수 있는 형식.

제품 라벨을 정확히 보존해야 한다면 생성 텍스트를 최종 원본으로 취급하지 않습니다. 원본 라벨 합성이나 별도 그래픽 작업이 필요한지 판단합니다.
